LoRaWAN-based IoT system using Arduino and Firebase
# LoRaWAN-Based IoT Data Transmission

# Overview

This project demonstrates long-range IoT communication using LoRaWAN technology. Data from sensors is transmitted using Arduino and uploaded to Firebase via The Things Network (TTN).

# Technologies Used

* Arduino
* LoRa Module
* The Things Network (TTN)
* Firebase

# Features

* Long-range wireless communication
* Real-time cloud data upload
* Low power consumption system

# Working

Sensor data is collected using Arduino, transmitted through LoRaWAN, received by TTN, and then pushed to Firebase for visualization.

# Results

* Successful long-range communication
* Stable real-time data transfer
